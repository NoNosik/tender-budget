# Прототип тендерного бюджета

Один файл `index.html`, публикуется на https://nonosik.github.io/tender-budget/ через GitHub Pages.
Весь скрипт лежит внутри замыкания, глобальных имён наружу нет: прогоны проверяют разметку, а не функции.

## Как запускать прогоны

Прогоны лежат в `~/Downloads/Автоматизация/ОЗМ/Бюджет/`, своего `node_modules` у них нет:

```
cd ~/Downloads/Автоматизация/ОЗМ/Бюджет/
NODE_PATH=~/bettrayer-app/node_modules node jsdom-run.js     ~/tender-budget/index.html
NODE_PATH=~/bettrayer-app/node_modules node jsdom-univer.js  ~/tender-budget/index.html
NODE_PATH=~/bettrayer-app/node_modules node jsdom-finplan.js ~/tender-budget/index.html
NODE_PATH=~/bettrayer-app/node_modules node jsdom-lenta.js   ~/tender-budget/index.html
NODE_PATH=~/bettrayer-app/node_modules node jsdom-changes.js ~/tender-budget/index.html
node chrome-420.js ~/tender-budget/index.html      # ширина на узком экране
node chrome-tab.js ~/tender-budget/index.html      # клавиатура в настоящем Chrome
```

`chrome-tab.js` водит настоящий Chrome через отладочный протокол: синтетический `KeyboardEvent`
родной переход фокуса не делает, и прогон был бы зелёным на сломанном коде.

## Правило: заход закрывается записью в «Что нового»

Каждый заход заканчивается записью в массиве `CHANGES`, иначе заход не считается закрытым.
Люди из двух отделов смотрят один и тот же адрес и должны понимать, что поменялось и зачем.

В записи версии обязательны:

- `date` — дата выкатки на Pages, та же, что у коммита;
- `label` — как заход называется между собой;
- `commits` — хэши, мелким серым для нас;
- у каждого `item` обязательны `what`, `why` и `source` (кто попросил или заметил, и когда);
- `ref` — номер из реестра замечаний, если у изменения он есть;
- `numbers` — на всё, что сдвинуло деньги: объект, что за цифра, было, стало, почему.
  У Догмы всегда указывать блок: «блок Встройка» или «Оба блока», это разные числа.
  Цифру, которую не подтверждает прогон, не писать вовсе.
- `check` — что стоит проверить читателю, если такое действие есть.

Аудиторию руками не задавать: она выводится из шага. Шаги 1-7 это расчётный отдел,
шаг 8 это руководители проектов, `step: 0` это сквозное и видно всем.

Тексты пишутся для человека, который прототип видит второй раз: ни имён из кода,
ни имён прогонов, ни длинных тире. Это проверяет `jsdom-changes.js`.

## Правила правок

- Один файл `index.html`, отдельных файлов и внешних сервисов нет.
- Русский язык, без длинных тире.
- Файлы Андрея в `Бюджет/` только читать.
- Любое число на экране с источником: адрес ячейки в файле или имя и дата разговора.
- Ожидания прогонов не подгонять. Если цифра поехала, сначала искать ошибку;
  если число изменилось осознанно, новое значение и причина идут в комментарий рядом с проверкой.
- Заход заканчивается коммитом, push и проверкой Pages по трём адресам:
  корень, `#lenta`, `#changes`.
